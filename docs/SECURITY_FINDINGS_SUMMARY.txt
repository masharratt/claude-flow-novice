================================================================================
CRITICAL VULNERABILITIES (4)
================================================================================

1. API KEY EXPOSURE VIA ENVIRONMENT VARIABLES
   Location:   entrypoint.sh, docker-compose.yml
   Impact:     API quota abuse, unauthorized API calls
   Attack:     Compromised agent → env | grep API → credential theft
   Fix Time:   4 hours (implement env var whitelisting)

2. DOCKER SOCKET PRIVILEGE ESCALATION
   Location:   Dockerfile.worker (usermod -aG docker-host)
   Impact:     Host system compromise
   Attack:     Compromised agent → docker run --privileged → root access
   Fix Time:   8 hours (implement sysbox or AppArmor)

3. PLAINTEXT .ENV VOLUME MOUNT
   Location:   docker-compose.yml (trigger-worker volumes)
   Impact:     Complete credential compromise
   Attack:     Agent reads /workspace/.env → all credentials exposed
   Fix Time:   6 hours (implement Docker secrets)

4. DATABASE CREDENTIALS IN ENVIRONMENT
   Location:   docker-compose.yml (DATABASE_URL env var)
   Impact:     Direct database access
   Attack:     docker inspect → parse DATABASE_URL → connect to postgres
   Fix Time:   4 hours (use secret management)

================================================================================
HIGH SEVERITY VULNERABILITIES (6)
================================================================================

1. AGENT_TYPE INPUT VALIDATION INSUFFICIENT
   - Whitespace bypass possible
   - Leading/trailing dashes allowed
   - Recommendation: Stricter regex with realpath verification

2. ENVIRONMENT VARIABLE INHERITANCE
   - No whitelist filtering for spawned processes
   - All parent env vars leaked to agents
   - Recommendation: Explicit variable passing, env -i execution

3. DEBUG MODE LEAKS SECRETS
   - API keys logged when DEBUG=true
   - No redaction in log output
   - Recommendation: Implement secret filtering in log functions

4. BASE IMAGE :LATEST TAG (NOT PINNED)
   - Mutable reference allows supply chain attacks
   - No signature verification
   - Recommendation: Pin to sha256 digest, verify cosign signature

5. NO npm AUDIT IN BUILD
   - Transitive dependencies not scanned
   - No CVE prevention in CI/CD
   - Recommendation: Add npm audit --production to Dockerfile

6. NO NETWORK POLICY ENFORCEMENT
   - All containers can reach all services
   - No network segmentation
   - Recommendation: Separate networks for backend/agents, implement policies
