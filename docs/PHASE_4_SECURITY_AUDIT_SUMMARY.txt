MEDIUM SEVERITY ISSUES (Must Fix Before Production)
================================================================================

ISSUE 1: JSON Payload Escaping Incomplete
Location: cfn-product-owner.ts lines 345-346
CVSS Score: 5.8 (Medium)
Status: UNFIXED

Description:
  JSON payloads only escape double quotes, missing $ and ` characters.
  If agent output contains backticks/dollars, shell interprets them.

Example Attack:
  { "feedback": "Test `whoami`" }
  Becomes: --loop3 "{"feedback":"Test `whoami`"}"
  Shell executes: whoami

Remediation:
  Add escaping for $ and ` in JSON serialization:
  const loop3Json = JSON.stringify(loop3Results)
    .replace(/"/g, '\\"')
    .replace(/\$/g, '\\$')
    .replace(/`/g, '\\`');

Impact: HIGH - Must fix before production
Effort: 5 minutes


ISSUE 2: Overly Broad Decision Parsing
Location: cfn-product-owner.ts line 408
CVSS Score: 4.3 (Medium)
Status: UNFIXED

Description:
  Final regex pattern /(PROCEED|ITERATE|ABORT)/i matches keywords anywhere
  Could match these words in natural language, causing false positives

Example False Positive:
  "The system will PROCEED with caution"
  Expected: decision not found
  Actual: decision = PROCEED (WRONG!)

Remediation:
  Remove the bare keyword pattern, keep specific patterns only:
  const patterns = [
    /(?:product\s{1,3}owner\s{1,3})?decision[:\s=]{1,3}(PROCEED|ITERATE|ABORT)/i,
    /\*{1,3}\s*(PROCEED|ITERATE|ABORT)\s*\*{1,3}/i,
  ];

Impact: HIGH - Could cause incorrect iteration decisions
Effort: 5 minutes


ISSUE 3: Missing Timeout Upper Bound
Location: cfn-loop2.ts line 127, cfn-product-owner.ts line 89
CVSS Score: 4.7 (Medium - DoS)
Status: UNFIXED

Description:
  Timeout validation accepts any positive number with no upper bound.
  Malicious client could specify timeout: 999999999999 (indefinite hang)

Remediation:
  Add max constraint to Zod schema:
  timeout: z.number()
    .positive()
    .max(3600000)  // Max 1 hour
    .default(1200000)

Impact: MEDIUM - DoS mitigation
Effort: 5 minutes
