## Research Methodology

**Source Selection Criteria:**
- Primary sources prioritized (official docs > third-party)
- Recent sources (2024-2026) for current state
- Multiple independent sources for consensus
- Mix of academic (validation), community (consensus), and vendor sources
- Cross-verification of facts across sources

**Validation Process:**
1. Gathered initial information via web search (4 queries)
2. Fetched official documentation (3 sources)
3. Cross-referenced with comparative analyses
4. Validated bundle sizes and performance claims
5. Assessed licensing and maintenance status
6. Confirmed via community discussions (Hacker News)

**Confidence Scoring:**
- Source diversity (30%): Multiple independent sources for key claims
- Thematic consistency (30%): Agreement across sources on tradeoffs
- Evidence strength (20%): Data (bundle sizes, performance) vs opinion
- Novelty/recency (20%): Information from 2025-2026 sources
