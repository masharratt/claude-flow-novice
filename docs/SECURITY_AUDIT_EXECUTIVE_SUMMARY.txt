CRITICAL VULNERABILITIES (Blocking)
================================================================================

1. REDIS KEY INJECTION (CRITICAL)
   Files: store-success-criteria.sh, get-success-criteria.sh
   Issue: TASK_ID not validated before Redis key construction
   Impact: Namespace pollution, key hijacking, data access control bypass
   Fix Time: 15 minutes per file
   
   Vulnerable Code:
   REDIS_KEY="swarm:${TASK_ID}:config:success_criteria"
   
   Fix:
   TASK_ID=$(sanitize_input "$TASK_ID" 64) || exit 1
   REDIS_KEY="swarm:${TASK_ID}:config:success_criteria"

2. SHELL INJECTION VIA JSON (CRITICAL)
   File: orchestrate.sh (line 502)
   Issue: Unescaped JSON in Docker environment variable
   Impact: Remote code execution, arbitrary command execution
   Fix Time: 20 minutes
   
   Fix:
   ENCODED=$(echo -n "$AGENT_SUCCESS_CRITERIA" | base64 -w0)
   DOCKER_CMD="... --env AGENT_SUCCESS_CRITERIA_B64=\"$ENCODED\""

3. JSON DOS VULNERABILITY (HIGH)
   File: orchestrate.sh (line 380)
   Issue: Unbounded JSON parsing, no size limits
   Impact: Memory exhaustion, service DoS, process crash
   Fix Time: 10 minutes
   
   Fix:
   JSON_SIZE=$(echo -n "$redis_context" | wc -c)
   if [ "$JSON_SIZE" -gt $((10*1024*1024)) ]; then exit 1; fi

4. RACE CONDITION IN AGENT STORAGE (HIGH)
   File: orchestrate.sh (lines 565, 582)
   Issue: Non-atomic SADD/SMEMBERS operations
   Impact: Lost agent IDs, orchestration failure, hangs
   Fix Time: 30 minutes
   
   Fix:
   Use Lua script for atomic operation with EXPIRE

5. NON-FATAL TTL FAILURE (MEDIUM)
   File: store-success-criteria.sh (line 65)
   Issue: Continues on EXPIRE failure
   Impact: Memory leak, indefinite key retention
   Fix Time: 5 minutes
   
   Fix:
   Make EXPIRE failure exit with error code
