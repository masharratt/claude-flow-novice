Issue (SUGGESTION): Dead code in error handling pattern
Location: Lines 139, 178, 267, 278, 566-568

Current pattern:
  TASK_ID=$(sanitize_input "$2") || { echo "Invalid"; exit 1; }

Analysis:
  The function never returns non-zero (echo always succeeds), so the
  "|| { exit 1; }" clause is unreachable. The sanitization works fine,
  but the pattern is misleading for future maintainers.

Options:
  1. Simplify: TASK_ID=$(sanitize_input "$2")
  2. Add validation: [[ -n "$(sanitize_input "$2")" ]] || exit 1

Impact: Cosmetic only - no functional or security change needed.
