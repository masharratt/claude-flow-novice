CRITICAL FINDING: CWE-22 PATH TRAVERSAL
═════════════════════════════════════════════════════════════════════════════

Location: .claude/skills/cfn-loop-orchestration/src/orchestrate.ts (lines 777-779)

Vulnerable Code:
  /^jest [a-z0-9/_.-]+$/
  /^mocha [a-z0-9/_.-]+$/

Issue:
  Character class [a-z0-9/_.-] includes dot (.), which allows consecutive dots (..)
  enabling directory traversal attacks.

Attack Examples:
  jest ../../../etc/passwd.test.ts    (PASSES - should FAIL)
  mocha ../../.env.test.js            (PASSES - should FAIL)
  jest ../../secrets/api_keys.test.ts (PASSES - should FAIL)

Impact:
  Severity: MEDIUM (CWE-22)
  Scope: Read arbitrary files from filesystem
  CVSS: 5.3 (after command injection mitigation)

Exposed Data Risk:
  - Configuration files (.env, secrets.json)
  - Source code from sibling projects
  - Private keys and credentials
  - System files (if elevated privileges)

REMEDIATION OPTIONS
═════════════════════════════════════════════════════════════════════════════

OPTION 1: Conservative - Remove Dots (RECOMMENDED)
  Recommendation: IMPLEMENT THIS OPTION

  Change:
    FROM: /^jest [a-z0-9/_.-]+$/
    TO:   /^jest [a-z0-9/_-]+$/
    FROM: /^mocha [a-z0-9/_.-]+$/
    TO:   /^mocha [a-z0-9/_-]+$/

  Impact: MINIMAL
    ✓ Blocks all path traversal attempts
    ✓ Still allows: jest tests/unit.test.ts
    ✓ Still allows: mocha tests/api.test.js
    ✗ Blocks: jest ../../../etc/passwd.test.ts

  Security Gain: Eliminates CWE-22 vulnerability
  Performance: No impact
  Complexity: Minimal code change
  Testing: No regressions expected

OPTION 2: Negative Lookahead (More Flexible)

  Change:
    FROM: /^jest [a-z0-9/_.-]+$/
    TO:   /^jest (?!.*\.\.)([a-z0-9/_.-]+)$/

  Benefit: Retains dot support while blocking '..' sequences
  Downside: More complex regex

OPTION 3: Path Prefix Restriction (Most Secure)

  Change:
    FROM: /^jest [a-z0-9/_.-]+$/
    TO:   /^jest tests\/[a-z0-9/_.-]+$/

  Benefit: Eliminates all path traversal by design
  Downside: Requires 'tests/' directory structure
