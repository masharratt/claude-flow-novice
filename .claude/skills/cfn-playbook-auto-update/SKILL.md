# Playbook Auto-Update Skill

## Purpose
Automatically update playbook with insights from sprint retrospectives.

## Core Responsibilities
- Parse retrospective JSON
- Update agent performance metrics
- Store successful strategies
- Increment pattern counters
- Maintain historical performance data

## Update Strategy
- Incremental updates
- Preserve historical context
- Allow rollback/review of changes
- Ensure data integrity

## Performance Tracking
- Per-agent performance by task type
- Confidence score trending
- Execution frequency
- Improvement over time

## Safety Mechanisms
- Validation of input data
- Backup of previous playbook version
- Logging of all modifications
- Ability to revert changes
