================================================================================

Vulnerability 1: Environment Variable Command Injection (CVSS 9.8)
  Location:     orchestrate.sh:518-572
  Attack:       export CFN_DOCKER_IMAGE="image; malicious_command"
  Risk:         Remote Code Execution as orchestrator process
  Fix:          sanitize_docker_var() + array-based execution
  Status:       FIXED ✓

Vulnerability 2: Base64 Denial of Service (CVSS 8.6)
  Location:     orchestrate.sh:547-558
  Attack:       7.5MB input → 10MB+ after encoding
  Risk:         Memory exhaustion, service crash
  Fix:          Post-encoding size validation with 10MB cap
  Status:       FIXED ✓

Vulnerability 3: Iteration Bounds Not Validated (CVSS 7.5)
  Location:     orchestrate.sh:161 (MAX_ALLOWED_ITERATIONS=100)
  Attack:       --max-iterations 1000000
  Risk:         Resource exhaustion via unbounded agent spawning
  Fix:          Multi-stage validation bounded to 100 iterations
  Status:       FIXED ✓
