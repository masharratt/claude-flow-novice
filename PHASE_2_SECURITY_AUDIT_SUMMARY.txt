CRITICAL FINDINGS (BLOCKING)
================================================================================

1. SECRET FILE PERMISSIONS
   File: docker/trigger-dev/.secrets/* (all 10 files)
   Current: 0777 (rwxrwxrwx - world-readable)
   Required: 0600 (rw------- - owner only)
   CVSS: 8.9 (CRITICAL)
   Impact: All API keys exposed to unprivileged users
   Fix Time: 5 minutes

   Solution:
   $ chmod 600 docker/trigger-dev/.secrets/*

2. SECRET DIRECTORY PERMISSIONS
   Directory: docker/trigger-dev/.secrets/
   Current: 0777 (drwxrwxrwx - world-writable)
   Required: 0700 (drwx------ - owner only)
   CVSS: 7.5 (HIGH)
   Impact: Attackers can inject/modify/delete secrets
   Fix Time: 5 minutes

   Solution:
   $ chmod 700 docker/trigger-dev/.secrets/

3. .ENV VOLUME MOUNT EXPOSURE
   File: docker/trigger-dev/docker-compose.yml (line 303)
   Issue: Root .env mounted into worker container
   CVSS: 7.2 (HIGH)
   Impact: If agent escapes, credentials available
   Fix Time: 1-2 hours

   Solution: Remove -../../.env:/workspace/.env:ro mount
   Use Docker secrets or env-only injection instead
