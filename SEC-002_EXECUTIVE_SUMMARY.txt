SECURITY PATTERNS APPLIED
================================================================================

1. SANITIZATION + ARRAY EXECUTION
   Pattern: Whitelist validation + array-based command execution
   Impact:  Prevents shell metacharacter interpretation
   Example: DOCKER_CMD=(...); "${DOCKER_CMD[@]}"  # No eval

2. POST-ENCODING SIZE VALIDATION
   Pattern: Measure size AFTER transformation, not before
   Impact:  Prevents encoding expansion bypass
   Example: ENCODE(); CHECK(size); EXIT on violation

3. MULTI-STAGE INPUT VALIDATION
   Pattern: Format check → Upper bound → Lower bound
   Impact:  Early detection of invalid inputs
   Example: Regex → Range check → Range check → Accept/Reject

4. EXPLICIT WHITELISTING
   Pattern: Specify allowed characters, reject everything else
   Impact:  Prevents bypass via unexpected character encoding
   Example: pattern="^[a-zA-Z0-9._:/-]+$"  # Explicit whitelist

5. FAIL-FAST PATTERN
   Pattern: Exit immediately on validation failure
   Impact:  Prevents propagation of invalid data
   Example: sanitize() || exit 1
