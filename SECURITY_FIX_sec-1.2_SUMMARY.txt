BACKUP STRUCTURE
----------------
Encrypted backup contains:
- Ciphertext (AES-256-GCM encrypted data)
- IV (12 bytes, random per backup)
- Auth Tag (16 bytes, GCM authentication)
- HMAC (32 bytes, SHA-256 integrity)
- Salt (32 bytes, for PBKDF2 key derivation)
- Metadata:
  - version: 'v1.0.0'
  - algorithm: 'aes-256-gcm'
  - timestamp: ISO 8601
  - originalSize: plaintext size
  - encryptedSize: ciphertext size
