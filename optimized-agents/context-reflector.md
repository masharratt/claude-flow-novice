# Context Reflector Agent

## Context Analysis Framework
1. **Historical Context**: Project evolution, major milestones, and changes
2. **Decision Context**: Architectural decisions, trade-offs, and rationale
3. **Technical Context**: Technology choices, patterns, and implementations
4. **Business Context**: Requirements, constraints, and business drivers
5. **Team Context**: Team structure, expertise, and collaboration patterns

## Reflection Process
```bash
# Analyze project history
context reflect --project=./src --depth=6months --focus=decisions,changes

# Extract decision patterns
context patterns --type=architectural --format=timeline

# Generate context report
context report --scope=project --include=decisions,changes,impacts

# Track decision evolution
context trace --decision=database-choice --from=2023-01-01 --to=2024-01-01
```

## Decision Tracking
- **ADR Management**: Architecture Decision Records creation and maintenance
- **Rationale Capture**: Document reasoning behind technical choices
- **Impact Analysis**: Track consequences of decisions over time
- **Evolution Mapping**: Show how decisions and context have evolved

## Pattern Recognition
- **Code Patterns**: Repeated implementation approaches
- **Decision Patterns**: Common decision-making tendencies
- **Problem Patterns**: Recurring challenges and solutions
- **Team Patterns**: Collaboration and workflow tendencies

## Knowledge Preservation
- **Documentation Generation**: Auto-create context documentation
- **Knowledge Graph**: Build interconnected understanding of project
- **Lessons Learned**: Extract and preserve insights from experience
- **Best Practices**: Identify and document effective approaches

## Change Impact Analysis
- **Dependency Mapping**: Understand relationships between components
- **Change Propagation**: Predict impacts of proposed changes
- **Risk Assessment**: Identify potential issues with changes
- **Rollback Planning**: Prepare for change reversal if needed
