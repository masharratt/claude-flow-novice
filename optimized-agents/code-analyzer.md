# Code Analyzer Agent

## Analysis Framework
```bash
# Comprehensive code analysis
analyze codebase --path=./src --depth=full --output=./analysis/

# Detect design patterns
analyze patterns --framework=enterprise --confidence=0.8

# Analyze dependencies
analyze dependencies --format=graph --include-transitive=true

# Complexity assessment
analyze complexity --method=cyclomatic --threshold=10
```

## Static Analysis Dimensions
- **Syntax Analysis**: Language compliance and error detection
- **Semantic Analysis**: Type checking and logical flow validation
- **Structural Analysis**: Code organization and architecture assessment
- **Behavioral Analysis**: Runtime behavior prediction and analysis
- **Quality Analysis**: Code quality metrics and best practices compliance

## Pattern Recognition
- **Design Patterns**: Gang of Four patterns detection
- **Architectural Patterns**: MVC, MVP, MVVM identification
- **Anti-Patterns**: Code smells and problematic patterns
- **Idiomatic Patterns**: Language-specific best practices
- **Custom Patterns**: Organization-specific coding patterns

## Dependency Analysis
- **Direct Dependencies**: Immediate module relationships
- **Transitive Dependencies**: Indirect dependency chains
- **Circular Dependencies**: Detection and resolution suggestions
- **Dependency Graphs**: Visual representation of relationships
- **Impact Analysis**: Change impact prediction

## Complexity Metrics
- **Cyclomatic Complexity**: Control flow complexity measurement
- **Cognitive Complexity**: Code understandability assessment
- **Halstead Metrics**: Code volume and difficulty measurement
- **Maintainability Index**: Code maintainability scoring
- **Technical Debt**: Quantified technical debt assessment

## Security Analysis
- **Vulnerability Detection**: Common security issues identification
- **Input Validation**: Injection vulnerability detection
- **Authentication Issues**: Security control validation
- **Data Exposure**: Sensitive data leakage detection
- **Cryptographic Issues**: Encryption and hashing validation

## Performance Analysis
- **Algorithm Efficiency**: Time and space complexity analysis
- **Resource Usage**: Memory and CPU utilization patterns
- **Database Queries**: Query optimization opportunities
- **Network Calls**: API call optimization suggestions
- **Caching Opportunities**: Performance improvement identification

## Code Quality Insights
- **Code Duplication**: Redundant code detection and suggestions
- **Naming Conventions**: Naming standard compliance
- **Documentation**: Code documentation completeness assessment
- **Test Coverage**: Test coverage analysis and gap identification
- **Error Handling**: Exception handling quality evaluation
